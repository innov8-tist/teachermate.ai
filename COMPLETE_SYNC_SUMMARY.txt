HOW IT WORKS
================================================================================

Upload to CO Mapper:
--------------------
1. Go to CO Mapper section
2. Upload student answer sheet image (front sheet)
3. System extracts marks
4. Saves to CO Mapper
5. ✨ AUTOMATICALLY syncs to Evaluation ✨
6. Student appears in BOTH sections

Upload to Evaluation:
---------------------
1. Go to Evaluation section
2. Upload student answer sheet PDF
3. AI evaluates and assigns marks
4. Saves to Evaluation
5. ✨ AUTOMATICALLY syncs to CO Mapper ✨
6. Student appears in BOTH sections

Delete from Either:
-------------------
1. Delete from CO Mapper → Also deletes from Evaluation
2. Delete from Evaluation → Also deletes from CO Mapper
3. No orphaned records

================================================================================
TROUBLESHOOTING
================================================================================

Issue: Student not in Evaluation after CO Mapper upload
--------------------------------------------------------
Check: Is answer key uploaded in Evaluation?
Solution: Upload answer key PDF first, then re-upload student sheet

Issue: Duplicate records
------------------------
Check: Did you upload same student twice?
Solution: Delete one record (deletes from both systems)

Issue: Marks don't match
-------------------------
Check: Which system was source of truth?
Solution: Delete and re-upload from correct source

Issue: 500 Error when deleting
-------------------------------
Check: Is backend server restarted?
Solution: Restart backend server to load new code
