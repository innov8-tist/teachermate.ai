================================================================================
DATABASE OPERATIONS
================================================================================

Delete from Evaluation:
-----------------------
1. DELETE FROM student_answer_evaluations WHERE progress_id = X
2. DELETE FROM student_evaluation_progress WHERE id = X
3. DELETE FROM co_student_answer_marks WHERE template_id = X AND regno = Y

Delete from CO Mapper:
----------------------
1. DELETE FROM co_student_answer_marks WHERE template_id = X AND regno = Y
2. DELETE FROM student_answer_evaluations WHERE progress_id IN (...)
3. DELETE FROM student_evaluation_progress WHERE schema_id IN (...)

================================================================================
BENEFITS
================================================================================

✅ Data Consistency - No orphaned records
✅ Single Action - Delete once, both systems updated
✅ No Conflicts - Re-uploading won't cause duplicates
✅ Clean Slate - Easy to correct mistakes
✅ Audit Trail - Console logs show what was deleted
✅ Transaction Safety - Rollback on errors

================================================================================
USE CASES
================================================================================

1. Student Withdrew from Course
   → Delete from CO Mapper
   → All data removed from both systems

2. Evaluation Error - Need to Re-evaluate
   → Delete from Evaluation
   → Can re-upload without conflicts

3. Wrong Student Data Uploaded
   → Delete from either section
   → Clean slate for correct data

4. Semester Reset
   → Delete all students from CO Mapper
   → All evaluation data also cleared

================================================================================
ERROR HANDLING
================================================================================

Template Not Found:
-------------------
⚠️ Warning: Template not found, CO mapper entries not deleted
Impact: Evaluation deleted, CO mapper remains
Solution: Manually delete CO mapper entries

No Evaluation Records:
----------------------
✓ Deleted 0 evaluation records
Impact: Only CO mapper deleted (expected if never evaluated)
Solution: No action needed

Database Error:
---------------
Error deleting student marks: [error message]
Impact: Transaction rolled back, no data deleted
Solution: Check database connection, verify IDs

================================================================================
TRANSACTION SAFETY
================================================================================

Both operations use database transactions:
- If any step fails → entire operation rolled back
- No partial deletions
- Data integrity maintained

Code pattern:
try:
    # Delete operations
    db.commit()
except Exception as e:
    db.rollback()
    raise e
